# Direction artistique — Di Nello Pizzeria (site 10)

**Angle** : le carton à pizza et le four — cartons imprimés napolitains, tickets de commande, affiches italiennes des années 60.

## Palette
| Rôle | Hex |
|---|---|
| Crème mozzarella (fond) | `#F6F0E1` |
| Kraft carton (texture CSS légère, header) | `#D9BF92` |
| Rouge tomate San Marzano (dominante, titres, CTA) | `#C3241C` |
| Vert basilic | `#2F6B33` |
| Noir four (texte, sections pleines) | `#1B1714` |

## Polices
- Titres : **Alfa Slab One** (`@fontsource/alfa-slab-one`)
- Texte : **DM Sans** variable (`@fontsource-variable/dm-sans`)

## Structure de l'accueil
1. Header en **couvercle de carton à pizza** : bande kraft avec rabat, impression rouge « Pizza Di Nello — 100 % napoletana » façon tampon.
2. Hero affiche années 60 : titre slab en rouge sur crème, grand cercle de pizza en SVG géométrique, 4,9/5, Commander à emporter (tel:) + Voir la carte, statut.
3. La carte en **ticket de commande** (numéros, cases à cocher visuelles, rubriques rouges / blanches / spéciales).
4. Pourquoi la napolitaine, offres du moment (étiquette agrafée), sur place / emporter / livraison, avis, infos.

## Élément signature
Carte façon ticket de commande + header couvercle de carton.

## Ce qui le distingue
Slab rétro unique dans les 17 sites ; kraft + rouge tomate + basilic. Diffère de De Grapp'En Verre (Abril Fatface, ardoise vert bouteille) et du Tabac (zinc, Anton condensé).
